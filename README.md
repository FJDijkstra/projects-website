# Website containing my projects

## Overview

This PHP website contains all projects I wanted to make. Most of these are fun games. The website include the following

### 1. Memory

A memory game where you have to match pictures. This game uses dutch memes as pictures

### 2. Maze

This page generates a maze in which you have to guide a mouse to the cheese by pressing the buttons on screen or the arrow keys.
This game also has a 2 player mode where you are racing againts eachother. One player uses the arrow keys and the other player the 'wasd' keys.

### 3. Size

Simple page letting you know how big your screen is.

### 4. Buzzer (WIP)

This will be a buzzer system, where you can be add a groupname and go to the buzzer page, where a big buzzer is shown, which you can click.
You can also go to the admin page where you get a log of who clicked the buzzer first and you can add points to teams.


## Getting Started

1. Download the repository.
2. Choose your database username and password and change it in config.php and the docker-compose.
3. Run docker compose up --build.
4. go to localhost:8080.
